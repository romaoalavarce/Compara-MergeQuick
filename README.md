# Compara-MergeQuick
Desenvolva um programa para testar os dois algoritmos apresentados: Merge Sort e Quick Sort.

No programa, o usuário deverá criar um array para ser ordenado e, em seguida, escolher um dos dois algoritmos para realizar a ordenação.

O usuário deverá definir o tamanho do array e o programa deverá criar randomicamente os valores para preencher esse valor.

Após a execução de cada um dos algoritmos, o programa deverá apresentar o tempo decorrido da ordenação.

Tudos os conteúdos necessários para a realização da atividade se encontram disponíveis na trilha. Por isso, os algoritmos utilizados precisam ser aqueles disponibilizados na trilha.

A atividade vai valer 1,0 ponto, será individual e precisa ser entregue até o final da aula de hoje.
